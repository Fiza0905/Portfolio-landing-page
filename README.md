# Portfolio Landing Page

A modern and elegant portfolio landing page designed for a Web & UI Designer. This project focuses on a clean, creative and responsive layout using HTML, CSS and Bootstrap 5.

## Features

- Creative hero section with portfolio title
- Web & UI Designer introduction
- Selected Work section
- Services section
- My Process section
- Autoplay background video
- Social media and contact information
- Responsive Bootstrap grid layout
- Clean and modern visual design

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5.3.8
- Bootstrap Grid System
- HTML5 Video

## Sections

### Hero Section
Introduces the designer with a creative portfolio banner, designer title and introduction.

### Selected Work
Displays four featured projects:
- Velure – Fashion Brand Web Design
- Calm by Design – Interior Studio Web Design
- Savor – Restaurant Web Design
- Forma Studio – Architecture Firm Web Design

### Services
Includes:
- Web Design
- UI/UX Design
- Brand Experience
- Design Strategy

### My Process
The design process is divided into four steps:
1. Discover
2. Design
3. Develop
4. Deliver

### Contact & Footer
Includes contact details, social media profiles and a call-to-action section.

## Project Purpose

This project was created as a portfolio landing page to practice and demonstrate frontend web development skills, including HTML, CSS, Bootstrap layout, responsive design and multimedia integration.
